# Personal Thoughts
This game is part of the Compilation of Final Fantasy VII which is a set of games, films, and short stories revolving around the world and characters of the original [[Final Fantasy 07|Final Fantasy VII]]. The entire compilation is a direct result of the original's international success and legacy. Crisis Core itself is not a game that I'm particularly fond of, it's action focused and the levels are repetitive. Furthermore, it's the type of prequel that introduces a lot of new lore and plot threads that run parallel to the work that it's ostensibly connected to. Instead of adding meaning to the original, it functions more as a jumping off point for other products.
