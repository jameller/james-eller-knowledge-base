# Significance
Sequels from this time have a reputation for being non-standard and Final Fantasy II certainly fits that mold. Instead of a job system, the progression system for each character is non-standard. They develop in different skills ranks via usage. For example, if I want a character to be really good with using a sword to attack, then I simply need to have that character attack with a sword frequently. The downside is that your character’s basic stats progress in the same way. If I want a character’s health to increase, then I need them to be hit a lot. This puts min-maxing players in a weird loop where their primary attackers wail on the other characters to boost attack stats for one and health stats for another. It was an interesting idea, but the execution is certainly lacking. To my knowledge, Square never replicated this progression system.
