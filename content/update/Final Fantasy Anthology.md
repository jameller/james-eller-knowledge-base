# Personal Thoughts
I was thrilled when this anthology initially released because it was my first opportunity to play [[Final Fantasy 05|Final Fantasy V]] as well as a port of [[Final Fantasy 06|Final Fantasy VI]] which is one of my favorite entries. The added CG scenes, while a bit rudimentary, were a great addition. I think this anthology is a great way to try both games if you have the PlayStation hardware for it.
