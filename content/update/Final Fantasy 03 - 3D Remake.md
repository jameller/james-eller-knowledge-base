# Personal Thoughts
I was so happy when this remake was released because it was the first time I had was able to play [[Final Fantasy 03|Final Fantasy III]] in any capacity because it had never previously been release in North America. I personally love the graphical style used and I don't mind the minor deviations from the original that some fans decry such as naming the four protagonists or the job-switching penalty.
